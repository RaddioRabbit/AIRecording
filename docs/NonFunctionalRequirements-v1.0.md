## 1. 概述

### 1.1 文档目的

本文档基于 PRD-v1.0 第 6 章非功能需求进行扩展和细化，为 AI 录音助手的架构设计、开发实现、测试验证和运维监控提供完整的非功能性需求基准。所有需求遵循 SMART 原则（Specific 具体、Measurable 可衡量、Achievable 可达成、Relevant 相关、Time-bound 有时限）。

### 1.2 适用范围

本文档适用于以下角色：
- 架构师：技术选型和系统设计的约束输入
- 开发工程师：编码实现的性能和安全基准
- QA 工程师：测试验收的量化标准
- 运维工程师：监控告警和容量规划的依据

| 需求编号 | 需求描述 | 指标 | 实现方式 | 优先级 |
|----------|----------|------|----------|--------|

| MTN-003 | 日志文件轮转 | 按日期轮转 | 每天生成一个日志文件，单文件不超过 100MB | P0 |
| MTN-004 | 日志保留策略 | 保留 30 天 | 自动清理 30 天前的日志文件 | P1 |
| MTN-005 | 敏感信息过滤 | 不记录敏感数据 | 日志中不包含 API 密钥、密码、录音内容等敏感信息 | P0 |
| MTN-006 | 用户可导出日志 | 一键导出 | 设置中提供"导出诊断日志"功能，便于问题排查 | P1 |

| MTN-008 | 错误率监控 | 自动上报 | 匿名上报错误发生频率和类型（需用户同意） | P1 |
| MTN-009 | 资源使用监控 | 内存/CPU/磁盘 | 监控并记录应用资源使用情况 | P1 |

- [ ] PERF-026：列表加载 100 条 < 1 秒

- [ ] COMP-006/COMP-007：适配浅色/深色模式
- [ ] COMP-017：简体中文界面完整
- [ ] COMP-023：内置麦克风兼容

#### 安全性验收

- [ ] SEC-001：录音文件可选 AES-256 加密
