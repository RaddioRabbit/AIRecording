## 1. 产品概述

### 1.1 产品定位
一款面向 macOS 用户的 AI 驱动录音与智能纪要生成工具。核心解决会议、访谈、课堂等场景下"录了音却没时间回听"的痛点，通过本地录音 + AI 转录 + 智能摘要，让用户在录音结束的同时获得结构化会议纪要。

### 1.2 目标用户
- 职场人士：需要记录会议内容并产出待办事项
- 内容创作者：访谈录音快速整理成文字稿
- 学生/研究者：课堂/讲座内容结构化归档
- 对隐私敏感的用户：不希望原始录音上传云端

### 1.3 核心价值主张
**"录音结束，纪要即出"** —— 在保护隐私的前提下，用最短路径将语音转化为可行动的结构化信息。

## 2. 范围边界

### 2.1 范围内（In Scope）
- macOS 桌面端原生应用（菜单栏常驻 + 主窗口）
- 本地音频录制（系统音频 + 麦克风输入）
- 语音转文字（本地 Apple Speech API / 本地 Whisper）
- AI 智能纪要生成（基于脱敏文本）
- 说话人分离与标识
- 会议纪要导出（Markdown / PDF / 文本）
- 录音历史管理与检索
- 基础图表生成（思维导图、流程图等，基于纪要文本）

### 2.2 范围外（Out of Scope）
- 跨平台支持（Windows / Linux / iOS / Android）
- 实时协作/多人共享功能
- 视频录制
- 云端音频存储与同步
- 第三方日历集成
- 实时翻译功能

### 2.3 隐私约束（Privacy Constraints）
- **原始音频文件不直接上传云端**
- 如需云端处理，上传对象应为：
  - 脱敏后的转录文本，或
  - 摘要后的结构化数据
- 本地录音文件默认存储在用户本地磁盘，提供可选加密
- 用户可完全离线使用基础功能（录音 + 本地转录）

## 3. 技术路线（待决策项）

### 3.1 决策说明
本 PRD 以**混合方案**为默认假设撰写功能定义和验收标准。技术路线本身作为正式待决策项保留，由架构师（claude-cp-arch）在后续阶段做最终技术选型。

### 3.2 三种方案利弊分析框架

#### 方案 A：纯本地方案
| 维度 | 评估 |
|------|------|
| 隐私性 | 最优，所有数据不出本地 |
| 离线能力 | 完整，无需网络即可使用全部功能 |
| 性能 | 受限于本地硬件，长录音处理较慢 |
| AI 质量 | 依赖本地模型，纪要生成质量可能低于云端大模型 |
| 包体积 | 大，需内置 Whisper 等模型 |
| 维护成本 | 中，需跟踪本地模型更新 |
| 适用场景 | 对隐私极度敏感、网络环境不稳定 |

#### 方案 B：纯云端方案
| 维度 | 评估 |
|------|------|
| 隐私性 | 差，原始音频或文本需上传第三方 |
| 离线能力 | 无，必须联网 |
| 性能 | 优，云端 GPU 加速处理 |
| AI 质量 | 最优，可使用最新大模型能力 |
| 包体积 | 小，仅客户端逻辑 |
| 维护成本 | 低，云端服务由供应商维护 |
| 适用场景 | 对隐私不敏感、追求最佳 AI 效果 |

#### 方案 C：混合方案（默认假设）
| 维度 | 评估 |
|------|------|
| 隐私性 | 良，原始音频不出本地，仅上传脱敏文本 |
| 离线能力 | 部分，本地录音+转录可离线，云端 AI 需联网 |
| 性能 | 良，本地转录 + 云端 AI 并行优化 |
| AI 质量 | 良，可使用云端大模型生成高质量纪要 |
| 包体积 | 中，需内置轻量转录模型 |
| 维护成本 | 中，需协调本地与云端组件 |
| 适用场景 | 平衡隐私与效果的绝大多数用户 |

### 3.3 架构师决策输入
架构师需基于以下因素做出最终选型：
1. 目标用户群体的隐私敏感度分布
2. 可接受的包体积上限
3. 云端 API 成本预算
4. 本地硬件最低配置要求
5. 未来扩展性需求

## 4. 功能模块

### 4.1 录音模块

#### 4.1.1 功能描述
提供一键录音能力，支持系统音频、麦克风或混合输入。

#### 4.1.2 用户故事
- 作为用户，我希望能从菜单栏一键开始录音，无需打开主窗口
- 作为用户，我希望可以选择录制系统音频、麦克风或两者混合
- 作为用户，我希望录音过程中能看到实时音量波形，确认录音正常进行
- 作为用户，我希望录音过程中可以暂停和继续

#### 4.1.3 功能详情
| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 菜单栏快速录音 | P0 | 点击菜单栏图标开始/停止录音 |
| 录音源选择 | P0 | 系统音频 / 麦克风 / 混合 |
| 实时波形显示 | P0 | 录音过程中的音量可视化 |
| 暂停/继续 | P1 | 录音过程中的暂停控制 |
| 录音计时显示 | P0 | 显示当前录音时长 |
| 快捷键支持 | P1 | 自定义全局快捷键开始/停止录音 |

#### 4.1.4 验收标准
- [ ] 从菜单栏点击到录音开始，延迟 < 500ms
- [ ] 支持录制系统音频（需获取系统权限）
- [ ] 支持录制麦克风输入
- [ ] 录音文件保存为 WAV/CAF 格式，采样率 >= 44.1kHz
- [ ] 录音过程中 CPU 占用 < 10%（M1 Mac）
- [ ] 1 小时录音文件大小 < 500MB

### 4.2 转录模块

#### 4.2.1 功能描述
将录音文件转换为文字，支持说话人分离。

#### 4.2.2 用户故事
- 作为用户，我希望录音结束后自动开始转录，无需手动操作
- 作为用户，我希望转录结果能区分不同说话人
- 作为用户，我希望转录过程中能看到进度提示
- 作为用户，我希望可以手动编辑转录结果中的错误

#### 4.2.3 功能详情
| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 自动转录触发 | P0 | 录音结束后自动开始 |
| 说话人分离 | P0 | 区分不同说话人并标识 |
| 转录进度显示 | P0 | 显示处理进度和预计剩余时间 |
| 转录结果编辑 | P1 | 手动修正转录错误 |
| 时间戳对齐 | P0 | 每个文本片段对应音频时间戳 |
| 多语言支持 | P1 | 中文、英文优先，支持语言自动检测 |

#### 4.2.4 验收标准
- [ ] 录音结束后 3 秒内自动开始转录
- [ ] 中文普通话识别准确率 >= 90%（安静环境）
- [ ] 英文识别准确率 >= 92%（安静环境）
- [ ] 说话人分离准确率 >= 80%（2-4 人场景）
- [ ] 转录速度 >= 0.5x 实时（即 1 小时录音 30 分钟内完成转录）
- [ ] 转录结果与音频时间戳误差 < 1 秒

### 4.3 纪要生成模块

#### 4.3.1 功能描述
基于转录文本，使用 AI 生成结构化会议纪要。

#### 4.3.2 用户故事
- 作为用户，我希望获得一份包含关键决策、待办事项、参与人的结构化纪要
- 作为用户，我希望纪要以 Markdown 格式呈现，便于复制和编辑
- 作为用户，我希望可以选择纪要的风格（简洁版 / 详细版）
- 作为用户，我希望纪要中的待办事项可以单独导出

#### 4.3.3 功能详情
| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 自动纪要生成 | P0 | 基于转录文本自动生成 |
| 关键信息提取 | P0 | 提取决策、待办、参与人、时间 |
| 多风格模板 | P1 | 简洁版 / 详细版 / 待办清单版 |
| 待办事项导出 | P1 | 单独导出待办列表 |
| 纪要编辑 | P1 | 支持手动修改生成的纪要 |
| 历史版本 | P2 | 保存纪要修改历史 |

#### 4.3.4 验收标准
- [ ] 转录完成后 1 分钟内生成纪要（混合方案下）
- [ ] 纪要包含：会议主题、参与人、关键决策、待办事项、时间线
- [ ] 待办事项识别准确率 >= 85%
- [ ] 纪要内容忠实于原文，不虚构未提及的信息
- [ ] 支持中文和英文纪要生成

### 4.4 图表生成模块

## 5. 用户界面

### 5.1 界面结构
```
菜单栏图标
├── 快速录音 / 停止录音
├── 最近录音
├── 打开主窗口
└── 退出

主窗口
├── 侧边栏
│   ├── 录音列表
│   ├── 搜索框
│   └── 设置入口
├── 主内容区
│   ├── 录音详情页
│   │   ├── 音频播放器
│   │   ├── 转录文本（时间戳对齐）
│   │   └── AI 纪要
│   └── 新建录音页
│       └── 录音源选择 + 开始按钮
└── 状态栏
    └── 转录/生成进度
```

### 5.2 关键界面原型描述

#### 5.2.1 菜单栏录音状态
- 未录音：显示麦克风图标，点击开始录音
- 录音中：显示红色录音指示器 + 计时，点击停止
- 处理中：显示进度指示器

#### 5.2.2 录音详情页
- 顶部：音频播放器（播放/暂停、进度条、倍速）
- 中部：转录文本（按说话人分段，时间戳可点击跳转）
- 右侧/底部：AI 纪要（Markdown 渲染，可编辑）

#### 5.2.3 新建录音页
- 录音源选择卡片（系统音频 / 麦克风 / 混合）
- 开始录音大按钮
- 最近使用设置记忆

## 6. 非功能需求

### 6.1 性能需求
| 指标 | 目标值 |
|------|--------|
| 应用冷启动时间 | < 3 秒 |
| 菜单栏录音启动延迟 | < 500ms |
| 转录速度 | >= 0.5x 实时 |
| 纪要生成时间 | < 1 分钟（1 小时录音） |
| 内存占用（空闲） | < 200MB |
| 内存占用（转录中） | < 1GB |

### 6.2 兼容性需求
- 支持 macOS 12.0 (Monterey) 及以上
- 支持 Intel 和 Apple Silicon 架构
- 适配浅色/深色模式

### 6.3 安全性需求
- 录音文件可选 AES-256 加密存储
- 云端传输使用 TLS 1.3
- 不上传原始音频文件
- 本地数据库存储转录和纪要

### 6.4 可靠性需求
- 录音过程中应用崩溃，已录制内容不丢失
- 转录过程中断，支持断点续传
- 自动保存机制，防止数据丢失

## 7. 数据模型

### 7.1 核心实体

#### Recording（录音）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 唯一标识 |
| filePath | String | 音频文件本地路径 |
| duration | Int | 时长（秒） |
| sampleRate | Int | 采样率 |
| channels | Int | 声道数 |
| createdAt | DateTime | 创建时间 |
| title | String | 标题（可自动生成） |
| sourceType | Enum | 系统音频/麦克风/混合 |

#### Transcription（转录）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 唯一标识 |
| recordingId | UUID | 关联录音 |
| segments | [Segment] | 文本片段数组 |
| language | String | 识别语言 |
| completedAt | DateTime | 完成时间 |

#### Segment（文本片段）
| 字段 | 类型 | 说明 |
|------|------|------|
| startTime | Float | 开始时间（秒） |
| endTime | Float | 结束时间（秒） |
| speakerId | String | 说话人标识 |
| text | String | 转录文本 |

#### Summary（纪要）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 唯一标识 |
| recordingId | UUID | 关联录音 |
| markdownContent | String | Markdown 格式纪要 |
| keyDecisions | [String] | 关键决策列表 |
| actionItems | [ActionItem] | 待办事项列表 |
| participants | [String] | 参与人列表 |
| generatedAt | DateTime | 生成时间 |

#### ActionItem（待办事项）
| 字段 | 类型 | 说明 |
|------|------|------|
| content | String | 事项内容 |
| assignee | String | 负责人（可选） |
| deadline | DateTime | 截止日期（可选） |

## 8. 错误处理

### 8.1 用户可见错误
| 错误场景 | 处理方式 |
|----------|----------|
| 麦克风权限被拒绝 | 弹窗引导用户前往系统设置开启权限 |
| 磁盘空间不足 | 录音前检测，不足时提示并停止录音 |
| 转录失败 | 显示重试按钮，保留录音文件 |
| 云端 AI 服务不可用 | 提示用户检查网络，提供"仅使用本地转录"选项 |
| 音频文件损坏 | 提示用户文件无法读取，建议删除 |

### 8.2 静默恢复
| 场景 | 处理方式 |
|------|----------|
| 应用崩溃后重启 | 自动恢复未完成的录音（如可能） |
| 转录进程被终止 | 下次启动时自动重试 |
| 云端请求超时 | 自动重试 3 次，失败后提示用户 |

## 9. 验收标准汇总

### 9.1 P0 功能验收清单
- [ ] 菜单栏一键开始/停止录音
- [ ] 支持系统音频、麦克风、混合录制
- [ ] 录音过程中显示实时波形
- [ ] 录音结束后自动触发本地转录
- [ ] 转录结果按说话人分段并带时间戳
- [ ] 转录完成后自动生成结构化纪要
- [ ] 纪要包含关键决策、待办事项、参与人
- [ ] 录音历史列表展示和全文搜索
- [ ] 录音文件和纪要本地存储，不上传原始音频
- [ ] 支持 macOS 12+，Intel/Apple Silicon

### 9.2 性能验收清单
- [ ] 应用冷启动 < 3 秒
- [ ] 录音启动延迟 < 500ms
- [ ] 中文识别准确率 >= 90%
- [ ] 转录速度 >= 0.5x 实时
- [ ] 纪要生成 < 1 分钟（1 小时录音）

### 9.3 隐私验收清单
- [ ] 原始音频文件不上传云端
- [ ] 云端仅接收脱敏后的文本或结构化数据
- [ ] 用户可完全离线使用录音+本地转录功能
- [ ] 提供数据清除功能
