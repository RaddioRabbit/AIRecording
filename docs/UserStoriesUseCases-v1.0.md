### 3.2 录音模块用例

---

#### UC-REC-01：菜单栏快速录音

| 项目 | 内容 |
|------|------|
| **用例名称** | 菜单栏快速录音 |
| **用例编号** | UC-REC-01 |
| **参与者** | 用户（主要）、macOS 系统（次要） |
| **优先级** | P0 |
| **关联用户故事** | US-R-01 |

**前置条件**
1. 应用已安装并正在运行
2. 应用已获得麦克风录制权限（如选择麦克风/混合模式）
3. 应用已获得系统音频录制权限（如选择系统音频/混合模式）
4. 磁盘剩余空间 >= 500MB

**主流程**
1. 用户点击菜单栏应用图标
2. 系统显示下拉菜单，展示"开始录音"按钮
3. 用户点击"开始录音"
4. 系统检查录音源设置，若未设置则使用上次配置或默认配置（麦克风）
5. 系统开始录制音频，菜单栏图标变为红色录音状态并显示计时
6. 系统保存音频数据到临时文件
7. 用户点击菜单栏图标，选择"停止录音"
8. 系统停止录制，保存音频文件到配置路径
9. 系统在数据库创建录音记录
10. 系统自动触发转录流程（如设置为自动转录）

**备选流程**

**A1：录音源选择（首次录音或切换源）**
- 在主流程第 4 步，若用户未配置过录音源：
  1. 系统弹出录音源选择面板
  2. 用户选择系统音频 / 麦克风 / 混合
  3. 若选择系统音频或混合，系统提示用户安装/启用音频捕获驱动
  4. 用户确认后回到主流程第 5 步

**A2：使用快捷键开始录音**
- 在主流程第 1-3 步，用户可按下预设全局快捷键直接开始录音
- 跳过菜单交互，直接进入主流程第 4 步

**异常流程**

**E1：权限被拒绝**
- 在主流程第 5 步，若系统权限不足：
  1. 系统显示权限提示弹窗
  2. 提供"前往系统设置"按钮
  3. 用户授权后需重新触发录音

**E2：磁盘空间不足**
- 在主流程第 5 步，若磁盘空间不足：
  1. 系统检测剩余空间
  2. 若空间不足，显示警告并拒绝开始录音
  3. 提示用户清理磁盘或更改存储位置

**E3：音频设备被占用**
- 在主流程第 5 步，若目标音频设备被其他应用占用：
  1. 系统显示设备占用提示
  2. 建议用户关闭占用应用或选择其他录音源

**后置条件**
- 录音文件已保存到本地存储
- 数据库中已创建对应的 Recording 记录
- 菜单栏恢复为未录音状态

**验收标准**
- 从菜单栏点击到录音开始，延迟 < 500ms
- 录音文件保存为 WAV/CAF 格式，采样率 >= 44.1kHz
- 录音过程中 CPU 占用 < 10%（M1 Mac）
- 1 小时录音文件大小 < 500MB

### 3.3 转录模块用例

---

#### UC-TRN-01：自动转录触发

| 项目 | 内容 |
|------|------|
| **用例名称** | 自动转录触发 |
| **用例编号** | UC-TRN-01 |
| **参与者** | 用户（主要）、本地转录引擎（次要）、云端 AI 服务（次要，可选） |
| **优先级** | P0 |
| **关联用户故事** | US-T-01 |

**前置条件**
1. 录音已完成并保存
2. 转录引擎已就绪（本地模型加载完成或网络连接正常）
3. 用户未禁用自动转录功能

**主流程**
1. 录音停止后，系统等待 3 秒确保文件写入完成
2. 系统检查录音文件完整性
3. 系统将音频文件送入转录引擎
4. 系统显示转录进度和预计剩余时间
5. 转录引擎逐段处理音频，生成文本片段
6. 系统将转录结果保存到数据库
7. 系统更新录音状态为"转录完成"
8. 系统自动触发纪要生成（如设置为自动生成）

**备选流程**

**A1：手动触发转录**
- 若用户禁用了自动转录：
  1. 录音完成后状态为"待转录"
  2. 用户在历史列表中选择录音，点击"开始转录"
  3. 进入主流程第 3 步

**A2：离线模式**
- 若用户处于完全离线模式：
  1. 仅使用本地转录引擎

**异常流程**

**E1：转录引擎加载失败**
- 在主流程第 3 步，若转录引擎无法加载：
  1. 系统显示错误提示
  2. 提供"重试"和"检查设置"选项
  3. 录音状态保持为"转录失败"

**E2：音频文件损坏**
- 在主流程第 2 步，若文件完整性校验失败：
  1. 系统显示文件损坏提示
  2. 建议用户删除并重新录音

**E3：转录过程中断**
- 若转录过程中应用崩溃或进程被终止：
  1. 下次启动时检测未完成的转录任务
  2. 自动从中断点恢复转录

**后置条件**
- 转录文本已保存到数据库
- 每个文本片段包含时间戳和说话人标识
- 录音状态更新为"转录完成"或"转录失败"

**验收标准**
- 录音结束后 3 秒内自动开始转录
- 中文普通话识别准确率 >= 90%（安静环境）
- 英文识别准确率 >= 92%（安静环境）
- 转录速度 >= 0.5x 实时
- 转录结果与音频时间戳误差 < 1 秒

  1. 系统提示"内容过短，无法生成有意义的纪要"
  2. 直接展示转录文本，不生成纪要

- 结构化纪要已保存到数据库
- 关键决策、待办事项、参与人等字段已提取
- 录音状态更新为"纪要已生成"

**验收标准**
- 转录完成后 1 分钟内生成纪要（混合方案下）
- 纪要包含：会议主题、参与人、关键决策、待办事项、时间线
- 待办事项识别准确率 >= 85%
- 纪要内容忠实于原文，不虚构未提及的信息
- 支持中文和英文纪要生成

## 7. 附录

### 7.1 术语表

| 术语 | 定义 |
|------|------|
| P0 | 最高优先级，必须在本版本实现 |
| P1 | 高优先级，建议在本版本实现 |
| P2 | 中优先级，可在后续版本实现 |
| Persona | 用户角色原型，代表一类典型用户 |
| 用户故事 | 从用户角度描述的功能需求，格式："作为...我希望...以便..." |
| 用例 | 描述系统与参与者之间交互的详细场景 |
| 主流程 | 用例的标准成功路径 |
| 备选流程 | 用例的替代成功路径 |
| 异常流程 | 用例的错误处理路径 |
