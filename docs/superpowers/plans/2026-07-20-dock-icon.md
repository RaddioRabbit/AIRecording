# 程序坞图标常显 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 AIRecording 启动后程序坞（Dock）一直显示应用图标，菜单栏图标及全部现有功能不变。

**Architecture:** 将应用从 agent 应用（`LSUIElement = true` + `.accessory`）改为普通应用（删除 `LSUIElement` + `.regular`），并清理 `MenuBarController.openMainWindow()` 中因此冗余的 activation policy 调用。无新逻辑、无新组件。

**Tech Stack:** Swift / SwiftUI / AppKit，Swift Package Manager（无 Xcode 工程）。

**Spec:** `docs/superpowers/specs/2026-07-20-dock-icon-design.md`

---

## File Structure

- 修改 `AIRecording/Info.plist` — 删除 `LSUIElement` 键
- 修改 `AIRecording/App/AIRecordingApp.swift` — activation policy 改为 `.regular`
- 修改 `AIRecording/App/MenuBarController.swift` — 删除冗余的 `setActivationPolicy(.regular)`
- 修改 `AGENTS.md` / `CLAUDE.md` — 同步两处过时描述

无新增文件，无新增测试（本改动为 Info.plist/启动行为变更，现有 XCTest 不覆盖此层面，靠编译 + 人工验证）。

### Task 1: 修改 Info.plist 与启动代码

**Files:**
- Modify: `AIRecording/Info.plist:33-34`
- Modify: `AIRecording/App/AIRecordingApp.swift:29-30`
- Modify: `AIRecording/App/MenuBarController.swift:236`

- [ ] **Step 1: 删除 Info.plist 中的 LSUIElement**

在 `AIRecording/Info.plist` 中删除这两行：

```xml
    <key>LSUIElement</key>
    <true/>
```

- [ ] **Step 2: 启动时设置 .regular**

在 `AIRecording/App/AIRecordingApp.swift` 的 `applicationDidFinishLaunching` 中，将：

```swift
        // Hide dock icon, show only in menu bar
        NSApp.setActivationPolicy(.accessory)
```

改为：

```swift
        // Regular app: show icon in Dock as well as menu bar
        NSApp.setActivationPolicy(.regular)
```

- [ ] **Step 3: 删除 MenuBarController 中冗余调用**

在 `AIRecording/App/MenuBarController.swift` 的 `openMainWindow()` 中，将：

```swift
    @objc private func openMainWindow() {
        NSApp.setActivationPolicy(.regular)
        NSApp.activate(ignoringOtherApps: true)
```

改为：

```swift
    @objc private func openMainWindow() {
        NSApp.activate(ignoringOtherApps: true)
```
